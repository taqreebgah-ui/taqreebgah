# Taqreebgah Venues

A beautiful venue listing website for wedding and event spaces in Pakistan.

## Design System

**Color Palette:**
- Terracotta: `#C98D79`
- Dusty Rose: `#D9BFA9`
- Peach Cream: `#FFEAD6`
- Soft Apricot: `#B7B7A4`
- Sage Fern: `#A5A58D`
- Olive Green: `#6B705C`

**Typography:**
- Headings: Cormorant Garamond (serif)
- Body: DM Sans (sans-serif)

## Features

- **Homepage**: Hero section with search, occasion cards, featured venues, and CTA sections
- **Explore Venues**: Browse all available venues
- **About Us**: Company story and mission
- **Contact**: Get in touch with the team
- **List Your Venue**: For venue owners to submit their spaces

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` - Next.js App Router pages
- `components/` - Reusable React components
- `lib/` - Utility functions and data
- `hooks/` - Custom React hooks
- `public/` - Static assets (images, favicon, etc.)

## Tech Stack

- **Next.js 16.4.6** - React framework
- **React 19.3.0** - UI library
- **Tailwind CSS 4.3.3** - Styling
- **TypeScript** - Type safety
- **Lucide React** - Icons

## Notes

- The logo needs to be added to `/public/taqreebgah-logo.png` (currently using text)
- Images are served from `/public/` directory
